Built to Endure

The Lasting Edition is the Federation's permanent record: the work, the vision, and the reasoning behind both, kept in plain HTML that will still read cleanly decades from now.

Websites change. Companies close. Platforms fade. This edition is built to survive all three, so whoever finds the Federation later can see what was built and why.
